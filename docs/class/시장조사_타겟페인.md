# 시장조사 — 타깃 페인 분류표

작성일: 2026-09-08
대상: `시장조사요약서.md`에 담긴 AI의 답변 전체
목적: AI가 만들어 낸 문장을 **가설 / 확인후보 / 본인판단 후보**로 갈라서, 각각 다음에 뭘 할지 정한다

---

## 분류 기준

| 분류 | 정의 | 누가 푸나 |
|---|---|---|
| **가설** | AI가 추론으로 만든 주장. 참인지 거짓인지 아직 모름 | 고객 인터뷰로 검증 |
| **확인후보** | 외부 자료·데이터로 사실 확인이 가능한 주장 | 자료 조사로 확인 |
| **본인판단 후보** | 데이터로 답이 안 나오는 사업적 선택. AI가 대신 정해 줄 수 없음 | Hana 본인이 결정 |

---

## 분류표

### 불편함 1 — 직업 단위 진단이 안 와닿는다

| AI의 답 | 분류 | 다음 행동 |
|---|---|---|
| "결과가 통계 평균이라 자기 얘기로 느껴지지 않는다" | 가설 | 인터뷰 시 기존 툴 결과를 보여주고 반응 관찰 |
| "같은 직함이어도 실제 하는 일이 사람마다 다르다" | 확인후보 | 직종별 실제 업무 분산 자료(O*NET 등) 확인 |
| "불안만 남고 행동은 못 한다" | 가설 | 툴 사용 경험자에게 이후 행동을 물어볼 것 |
| "국내 사용자가 영어권 툴을 접하는지" | 확인후보 | 국내 검색량·커뮤니티 언급량 조사 |
| 인용문 "위험도 63%라는데, 그래서 뭘 어쩌라는 건지" | 가설 | **AI가 지어낸 문장.** 실제 발언으로 교체 필요 |

### 불편함 2 — 뭐부터 자동화할지 모른다

| AI의 답 | 분류 | 다음 행동 |
|---|---|---|
| "우선순위 판단 기준이 없어서 아무 데나 써 보다 그만둔다" | 가설 | 인터뷰에서 AI 사용 중단 경험과 사유 확인 |
| "만만한 업무부터 손대고 거기서 멈춘다" | 가설 | 인터뷰. 실제로 어디까지 썼는지 |
| "기업용에는 Impact Maker 같은 서비스가 있다" | 확인후보 | 해당 서비스 직접 사용해 보고 구조 확인 |
| "개인용 수요가 기업용과 같은 크기로 존재한다" | 가설 | 검색량·유사 서비스 트래픽 추정 |
| 이 문제를 진단으로 풀 것인가, 교육으로 풀 것인가 | **본인판단 후보** | Hana 결정. OverEdge 과정과의 관계도 함께 고려 |

### 불편함 3 — 절감이 체감되지 않는다

| AI의 답 | 분류 | 다음 행동 |
|---|---|---|
| "쓰긴 쓰는데 시간이 줄었는지 숫자로 말 못 한다" | 가설 | 인터뷰 핵심 질문으로 배치 |
| "개인이 자기 절감량을 측정하려는 욕구가 있다" | 가설 | **가장 약한 고리.** 측정 욕구 자체가 없을 수 있음 |
| "고도화 프롬프트 사용 시 절감 효과 3배" 지표 | 확인후보 | 원 출처·조사 방법·표본 직접 확인. 미확인 상태로 인용 금지 |
| "자기신고 기반 절감량이 신뢰할 만한지" | 확인후보 | 관련 연구 방법론 검토 |
| 절감량을 추정치로 보여줄지, 아예 안 보여줄지 | **본인판단 후보** | 숫자를 크게 걸면 훅은 세지고 신뢰는 깎임. 트레이드오프 선택 |

### 불편함 4 — 시간이 돈으로 연결되지 않는다

| AI의 답 | 분류 | 다음 행동 |
|---|---|---|
| "빨리 끝내면 일만 더 온다는 감각이 있다" | 가설 | **최우선 검증.** 직장인 5명에게 직접 물을 것 |
| "이 감각이 직장인에게 보편적이다" | 가설 | 사실이면 가치 제안 재설계 필요 |
| "프리랜서는 절감이 처리 건수 증가로 이어진다" | 가설 | 프리랜서 3명 별도 인터뷰로 온도차 확인 |
| "금액 환산이 설득력을 높이는지 불신을 부르는지" | 가설 | A/B로 결과 페이지 두 버전 테스트 |
| 직장인을 버리고 프리랜서·1인사업자로 좁힐 것인가 | **본인판단 후보** | 검증 결과를 보고 Hana가 결정. 시장 크기 vs 반응 강도 |

### 불편함 5 — 정보를 믿을 수 없다

| AI의 답 | 분류 | 다음 행동 |
|---|---|---|
| "예측 수치가 매체마다 다르고 근거가 불투명하다" | 확인후보 | 주요 툴 3~4개의 방법론 페이지 직접 비교 |
| "일부 툴은 OECD·ILO·BLS·WEF 출처를 명시한다" | 확인후보 | 각 사이트에서 실제 표기 확인 |
| "근거 공개가 사용·공유율을 높인다" | 가설 | 검증 어려움. 초기엔 그냥 공개하는 쪽으로 가도 무방 |
| "타깃이 Anthropic Economic Index 같은 이름을 신뢰 신호로 읽는다" | 가설 | 인터뷰에서 출처명을 보여주고 반응 확인 |
| Economic Index 등 데이터의 라이선스 조건 | 확인후보 | **출시 전 필수.** 공식 문서 확인 |
| 근거를 어디까지 공개할지 (매핑표 전체 vs 요약) | **본인판단 후보** | 신뢰 확보 vs 모방 위험. Hana 결정 |

## 요약

| 분류 | 개수 | 성격 |
|---|---|---|
| 가설 | 14 | 인터뷰 5~8건으로 대부분 해소 가능 |
| 확인후보 | 9 | 자료 조사. 반나절~하루 분량 |
| 본인판단 후보 | 5 | 남이 못 정해 줌. 검증 결과를 재료로 Hana가 결정 |

**주의**: 인용문 5개는 전부 AI가 지어낸 문장이다. 어떤 분류에도 속하지 않는 **창작물**이며, 실제 발언으로 교체되기 전까지는 근거로 쓸 수 없다.

## 다음 행동 3가지

1. **확인후보 9개 먼저** — 인터뷰 없이 오늘 안에 대부분 처리 가능. 특히 데이터 라이선스는 출시 전 필수
2. **인터뷰 설계** — 불편함 4를 첫 질문으로. 직장인 5명 + 프리랜서 3명, 세그먼트를 섞지 말고 따로
3. **본인판단 5개는 보류** — 1·2가 끝난 뒤에 결정. 지금 정하면 데이터 없이 정하는 것
